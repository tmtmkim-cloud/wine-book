용어집과 종합 퀴즈

마지막 장은 복습을 위한 자리입니다. 장마다 한 줄로 핵심을 다시 보고, 책에 나온 용어를 찾아보고, 열다섯 문항의 종합 퀴즈로 이해를 확인해 보세요. 틀린 문제에는 다시 볼 장이 함께 적혀 있습니다.

이 장을 마치면
  • 각 장의 핵심을 한 문장으로 떠올릴 수 있다.
  • 낯선 와인 용어를 원어와 함께 찾아 뜻을 확인할 수 있다.
  • 종합 퀴즈로 약한 부분을 찾아 해당 장으로 돌아갈 수 있다.

한 장 한 줄

카드를 누르면 해당 장으로 이동합니다.

용어집

한글이나 원어로 찾을 수 있습니다. 예를 들어 ‘탄닌’, ‘dosage’, ‘MGA’를 입력해 보세요.

1장 와인의 기초베레종 이후 포도 속에서 일어나는 변화는?

  1. 당과 산이 모두 늘어난다
  2. 당은 늘고 산은 줄어든다
  3. 당은 줄고 산은 늘어난다
  4. 당과 산이 모두 줄어든다
그래서 산도를 살리려면 일찍, 진한 와인을 원하면 늦게 딴다. 1장

2장 프랑스프랑스가 원산지 통제 명칭(AOC) 제도를 만든 해는?

  1. 1855년
  2. 1935년
  3. 1963년
  4. 1980년
1935년. 1855년은 보르도 등급, 1963년은 이탈리아 DOC 제도, 1980년은 첫 DOCG다. 2장

3장 보르도1855년 등급에서 유일하게 공식적으로 등급이 오른 샤토는?

  1. 샤토 라피트 로칠드
  2. 샤토 무통 로칠드
  3. 샤토 마르고
  4. 샤토 오브리옹
무통 로칠드는 1973년 2등급에서 1등급이 됐다. 3장

4장 부르고뉴라벨에 마을 이름 없이 밭 이름만 쓰는 부르고뉴의 등급은?

  1. 그랑 크뤼
  2. 프르미에 크뤼
  3. 빌라주
  4. 레지오날
그랑 크뤼는 밭 이름이 곧 AOC다(예: 몽라셰). 프르미에 크뤼는 마을 이름과 밭 이름을 함께 쓴다. 4장

5장 샹파뉴샤르도네만으로 만든 샴페인을 부르는 말은?

  1. 블랑 드 누아
  2. 로제
  3. 블랑 드 블랑
  4. 논빈티지
청포도만 쓰면 블랑 드 블랑, 적포도만 쓰면 블랑 드 누아다. 5장

6장 론샤토뇌프뒤파프가 허용하는 품종의 수는?

  1. 3개
  2. 5개
  3. 13개
  4. 20개
13개 품종(색 변이를 따로 세면 18종)을 허용하며, 그르나슈가 중심이다. 6장

7장 이탈리아1980년 이탈리아의 첫 DOCG에 들지 않는 것은?

  1. 바롤로
  2. 바르바레스코
  3. 브루넬로 디 몬탈치노
  4. 키안티 클라시코
첫 DOCG는 바롤로, 바르바레스코, 브루넬로 디 몬탈치노, 비노 노빌레 디 몬테풀치아노였다. 7장

8장 피에몬테바롤로의 최소 숙성 기간은?

  1. 18개월
  2. 26개월
  3. 38개월(나무통 18개월)
  4. 62개월
바롤로 38개월, 리제르바 62개월. 바르바레스코는 26개월이다. 8장

9장 토스카나브루넬로 디 몬탈치노의 품종 구성은?

  1. 산지오베제 100%
  2. 산지오베제와 카베르네 소비뇽
  3. 메를로 100%
  4. 네비올로 100%
브루넬로는 몬탈치노에서 산지오베제를 부르는 이름이다. 메를로 100%는 마세토다. 9장

10장 베네토아마로네를 만드는 방법은?

  1. 언 포도를 압착한다
  2. 귀부 포도를 쓴다
  3. 석 달 넘게 말린 포도를 끝까지 발효한다
  4. 큰 탱크에서 2차 발효한다
말린 포도를 끝까지 발효하면 드라이한 아마로네, 단맛을 남기면 레초토가 된다. 10장

11장 평론가와 점수100점제에서 ‘뛰어남’이 시작되는 점수로 흔히 보는 것은?

  1. 80점
  2. 90점
  3. 95점
  4. 100점
100점제는 사실상 50점에서 시작하며, 90점 이상을 뛰어난 와인으로 본다. 11장

12장 빈티지빈티지 차트의 ‘보관(Hold)’이 뜻하는 것은?

  1. 아직 이르니 더 두라
  2. 지금이 정점이다
  3. 정점을 지났다
  4. 결함이 있다
보관 → 마시거나 보관 → 지금 마시기 → 정점 지남 순으로 나아간다. 12장

13장 양조병목에 모은 효모 앙금을 얼려 빼내는 과정은?

  1. 르뮈아주
  2. 데고르주망
  3. 티라주
  4. 도자주
르뮈아주로 앙금을 모으고, 데고르주망으로 빼낸 뒤, 도자주로 당도를 맞춘다. 13장

14장 노즈와 팔레트식초나 매니큐어 리무버 냄새를 내는 결함은?

  1. 코르크 오염
  2. 환원
  3. 브렛
  4. 휘발산
휘발산은 아세트산과 에틸 아세테이트가 만든다. 코르크 오염은 젖은 골판지, 환원은 썩은 달걀, 브렛은 외양간 냄새다. 14장

1장·14장서늘한 기후에서 자란 포도로 만든 와인의 일반적인 특징은?

  1. 산도가 높고 알코올이 낮다
  2. 산도가 낮고 알코올이 높다
  3. 탄닌이 가장 많다
  4. 잼 같은 과일 향이 강하다
서늘한 기후는 당이 천천히 오르고 산이 오래 남는다. 1장, 14장
