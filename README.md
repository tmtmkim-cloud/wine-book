# WineBook · 와인 이해 교과서

프랑스와 이탈리아의 와인 산지를 밭 단위 지도로 읽고, 평론가 점수와 빈티지, 양조와 테이스팅 표현까지 그림과 실험으로 배우는 열다섯 장의 웹 교과서입니다.

- 시작: `index.html`
- 01 와인의 기초 `basics.html` · 02 프랑스 `france.html` · 03 보르도 `bordeaux.html` · 04 부르고뉴 `burgundy.html` · 05 샹파뉴 `champagne.html` · 06 론과 다른 산지 `rhone.html`
- 07 이탈리아 `italy.html` · 08 피에몬테 `piedmont.html` · 09 토스카나 `tuscany.html` · 10 베네토와 남부 `veneto.html`
- 11 평론가와 점수 `critics.html` · 12 빈티지와 시음 적기 `vintages.html` · 13 양조 `winemaking.html` · 14 노즈와 팔레트 `tasting.html` · 15 용어집과 종합 퀴즈 `review.html`

모든 페이지는 외부 스크립트 없이 하나의 HTML 파일로 동작합니다(웹 글꼴만 Google Fonts에서 불러옵니다).

## 지도 데이터

- 프랑스 행정 경계: france-geojson (IGN·INSEE 기반)
- 부르고뉴 포도밭 경계: INAO délimitations parcellaires (Licence Ouverte, OpenDataWine 경유)
- 이탈리아 행정 경계: openpolis geojson-italy (ISTAT 기반)
- 이탈리아 DOCG 경계: WineRegions (CC0)
- 해안선·하천: Natural Earth

점수·빈티지·생산량 수치의 출처는 각 장 끝의 ‘출처’에 적었습니다.
